#  Smart Vision Assistant Camera

### AI-Powered Smart Vision Assistant Using ESP32-CAM

## 📌 About The Project

The **Smart Vision Assistant Camera** is an AI-assisted embedded system designed to help users understand visual information through image processing, text recognition, and intelligent feedback.

The system uses an ESP32-CAM to capture images and processes visual information to provide useful outputs through audio feedback and an OLED display.

The main aim of this project is to make visual information easier to understand using Artificial Intelligence and Embedded Systems.

## ✨ Key Features

- 🖼️ **Image Description:** Provides descriptions of captured images.
- 📝 **Text Recognition (OCR):** Extracts text from images.
- 🌐 **Text Translation:** Helps translate recognized text into another language.
- ➗ **Math Assistance:** Provides assistance with basic mathematical problems.
- 🔊 **Audio Feedback:** Gives information through audio output.
- 📟 **OLED Display:** Displays useful information and system feedback.

## 🔄 Working Principle

1. The ESP32-CAM captures an image.
2. The captured image is processed for visual information.
3. OCR is used to recognize text when required.
4. AI-based processing helps interpret the visual information.
5. The result is provided through audio output and the OLED display.
